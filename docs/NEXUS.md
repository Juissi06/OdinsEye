# Nexus drafts

## Summary (short text under the title)
Valheim's debug and admin commands in one window: spawn items and creatures, time and weather, teleport, server admin and more. Follows the game's own cheat rules.

## Changelog / file description (0.3.0)
- Speed up everything around you: grow plants, finish smelters, kilns and fermenters, cook or burn food, fill beehives, regrow berries
- Grow up young creatures and heal your tames
- Set a creature's stars (0 to 4) from the Inspect tab
- Tape measure, your coordinates and a count of what's loaded around you
- Undo terrain changes in a radius, clear snow off your buildings

## Changelog / file description (0.2.0)
New Skills, Buffs, Creatures and Custom tabs; fun cheats (size, jump, speed, ship speed, infinite stamina, no weight limit, no wear, no fall damage, night vision, one-hit kills, super knockback, instant crafting); faster learning per skill; keep skills on death; search box; world modifiers and keys; unlock all recipes and pieces; console suggestions for your own buttons; spawn tamed; Back teleport; repair buildings; hotkeys; fixes.

## Changelog / file description (0.1.1)
- The achievements switch now says what it really does: while it's on you can earn achievements again, even on a character that used cheats

## Changelog / file description (0.1.0)
- First release: Player, Spawn, World, Teleport, Admin and Inspect tabs in one window (Home)

## Description for 0.2.0 (your live text kept word for word; new lines are only added)
Odin's Eye puts Valheim's debug and admin commands in one window, so you don't have to remember and type console commands anymore. Spawn items and creatures, change the time and weather, teleport anywhere on the map and run your server, all from one menu.
Every button runs the game's own console command, so it follows the game's rules.
Cheats work in single player and in worlds you host, once dev commands are on. On a dedicated server admins get the admin tools
Warning: using cheats marks your character as cheated and disables achievements, thought the mod has an option to turn them back on
Client-side
Installation
Mod managers: automatic install
Manual: put the DLL file in \Steam\steamapps\common\Valheim\BepInEx\plugins
Player
God mode, ghost mode, fly and no build cost as simple switches
Heal: back to full health and stamina
Fun cheats: giant or tiny, super jump, super speed, ship speed, infinite stamina, no weight limit, no wear, no fall damage, night vision, one-hit kills, super knockback and instant crafting
Back to normal: turns every fun cheat off at once
Skills
Every skill with its level, modded skills too: set any level, raise or reset them all
Learn up to 25 times faster, all skills or each one on its own, and keep your skills when you die
Buffs
Every status effect in the game with its icon, to add or clear
Pick any guardian power with its cooldown reset, and empty your stomach to try other food
Spawn
Every item and creature in the game with icons, categories and search
Pick the amount and quality, or stars for creatures, and spawn it in front of you or straight into your inventory
Favourites, recent spawns and the game's premade item sets
Spawn creatures already tamed, bosses ask first
World
Time of day, skip time, weather and wind
Game speed, raids and boss progress
Clean up: kill enemies, remove drops, stop monsters from spawning
World modifiers and presets, like on the world creation screen
Unlock all recipes and building pieces, and see, set or remove every world key
Teleport
Click anywhere on the map to go there
Saved spots for each world
Shortcuts to Haldor, Hildir, the Bog Witch and every boss altar, and the nearest biome of each kind
Go to or bring other players
Back: return to where you were before your last teleport
Creatures
Tame, make neutral creatures angry, passive monsters and freeze every creature
A list of the creatures nearby to tame, untame or kill one by one
Admin
Save the world, kick and ban players, unban
Turn portals or the map off, reveal or forget the map
Delete everything around you, set fuel, put out fires, repair your gear
Repair every building around you
Inspect
See what you're looking at: prefab name, owner, health, creature level and what it's after
Custom
Make your own buttons from any console line, with suggestions as you type
Search
Find any feature from the search box in the title bar
Default keys
Home open and close the window
Esc close the window
Hotkeys for god mode, ghost mode, fly, no build cost and Back: set them in the config
Requirements
BepInEx
Valheim Configuration Manager (optional, but recommended for config)
