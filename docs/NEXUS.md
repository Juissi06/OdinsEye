# Nexus drafts

## Summary (short text under the title)
Valheim's debug and admin commands in one window: spawn items and creatures, time and weather, teleport, server admin and more. Follows the game's own cheat rules.

## Changelog / file description (0.1.0)
- First release: Player, Spawn, World, Teleport, Admin and Inspect tabs in one window (Home)

## Description
THIS MOD IS STILL IN ALPHA
Odin's Eye puts Valheim's debug and admin commands in one window, so you don't have to remember and type console commands anymore. Spawn items and creatures, change the time and weather, teleport anywhere on the map and run your server, all from one place. Every button runs the game's own console command, so it follows the game's rules.
Client-side and fully customisable.
Installation
Mod managers: automatic install
Manual: put the DLL file in \Steam\steamapps\common\Valheim\BepInEx\plugins
Player
God mode, ghost mode, fly and no build cost as simple switches
Heal: back to full health and stamina
Achievements: a switch for the game's own option that lets cheated items count for achievements again
Spawn
Every item and creature in the game with icons, categories and search
Pick the amount and quality, or stars for creatures, and spawn it in front of you or straight into your inventory
Favourites, recent spawns and the game's premade item sets
World
Time of day, skip time, weather and wind
Game speed, raids and boss progress
Clean up: kill enemies, remove drops, stop monsters from spawning
Teleport
Click anywhere on the map to go there
Saved spots for each world
Shortcuts to Haldor, Hildir, the Bog Witch and every boss altar, and the nearest biome of each kind
Go to or bring other players
Admin
Save the world, kick and ban players, unban
Turn portals or the map off, reveal or forget the map
Delete everything around you, set fuel, put out fires, repair your gear
Inspect
See what you're looking at: prefab name, owner, health, creature level and what it's after
Good to know
Cheats work in single player and in worlds you host, once dev commands are on. On a dedicated server admins get the admin tools, just like in the console.
The window warns you before your first cheat: using cheats marks your character as cheated for achievements.
Hover a button to see the console command it runs
Destructive actions like killing everything or deleting ask first

Drag the window by its title to move it, it remembers where you put it.
Default keys(changeable in the config)
Home open and close the window
Esc close the window
Requirements
BepInEx
Valheim Configuration Manager (optional, but highly recommended for config)
