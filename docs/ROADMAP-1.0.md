# Odin's Eye 1.0.0

The scope from the start is done: the game's debug and admin commands, building and admin tools, a small inspector,
plus the 0.3.0 tools. 1.0 is about trusting it in multiplayer, not about more buttons.

## 1. Multiplayer test session
- [ ] **Hosted world with a friend**: cheats work for the host only, the friend sees them refused with the game's reason.
- [ ] **Dedicated server**: an admin gets the Admin tab (save, kick, ban, unban), a non-admin doesn't; cheats stay off.
- [ ] **Own-cheat tools on things another player owns** (they take ownership first): finish production, cook, fill hives, regrow, grow plants, grow up young, heal tames, set stars, undo terrain, clear snow, repair buildings. Nothing doubled, nothing lost, the other player sees the result.
- [ ] **Undo terrain** next to terrain another player changed, and across a zone border.
- [ ] **Teleport**: go to / bring players, Back, map click, on a server.
- [ ] **Achievements switch** and the cheat mark on characters behave as the game does.
