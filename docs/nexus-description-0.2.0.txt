Odin's Eye puts Valheim's debug and admin commands in one window, so you don't have to remember and type console commands anymore. Spawn items and creatures, change the time and weather, teleport anywhere on the map and run your server, all from one menu.

Every button runs the game's own console command, so it follows the game's rules.

Cheats work in single player and in worlds you host, once dev commands are on. On a dedicated server admins get the admin tools

[color=#ff6f55]Warning: using cheats marks your character as cheated and disables achievements, thought the mod has an option to turn them back on[/color]
