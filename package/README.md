# Odin's Eye

One Valheim-style window for the game's debug and admin commands. Press **Home** in game to open it.

## Installation
- **Mod manager (r2modman, Thunderstore Mod Manager):** install it from the manager. BepInEx is installed with it.
- **Manual:** install [BepInExPack Valheim](https://thunderstore.io/c/valheim/p/denikson/BepInExPack_Valheim/), then put `OdinsEye.dll` in `Valheim\BepInEx\plugins`.
